# 桃花瘴迷踪阵（maze.exe）· 笔记（已解）

## 关键点
- 附件 `maze.exe`（111,598 B，PE64）。运行显示「后山禁地 · 桃花瘴迷踪阵」，读一行走位（w/a/s/d），
  从 (1,1) 走到 (19,19) 的 21×21 = 441 块砖。
- 程序结构：`.pdata` 里有大量小函数，每个对应一块砖；函数体对 `eax`（走位字符）做
  `cmp eax, 'w'/'a'/'s'/'d'` + `je`：
  - 命中后跳转块里 `lea rax, [rip+disp]` → 下一块砖的地址（生路）；
  - 或 `call <trap>` / `mov eax, 0` → 禁制（死路）。
- 起点 = `ImageBase + 0x17aa`，终点 = `ImageBase + 0x8644`（对应 (1,1) 与 (19,19)）。
- **反向建图**：解析每个砖块函数的 4 个方向转移，得到有向图（199 个可走砖块、232 个禁制函数）；
  **BFS** 从起点到终点得最短走位：
  `ddddddssddddssddwwddddssaassddssaassssddssssaassdddd`（52 步）。
- 喂给原 exe：输出「你踏上最后一块青砖…阵心石台缓缓升起一面玉简：**NEX{m4ze_p4th_1s_k3y}** 迷踪阵，破！」exit 0。

## 判定
- BFS 路径终点 == 程序里的 win 函数（0x8644），且每一步都落在合法砖块函数上；
- 原 exe 输入该走位：exit 0 + 「迷踪阵，破！」+ 回显 flag；
- flag 命中 `NEX{...}` 正则。

## 失败分支（排除理由）
- 不靠猜路线：441 块砖、半数为禁制，棋盘大且无图，纯手动试错必失败；
- 不动态调试找坐标：把每个砖块函数当作图节点、方向当边，静态建图更直接；
- 注意“死路”不是 `lea` 而是 `call trap`，解析时要区分，否则会把禁制砖当成通路。

## 可复用 TTP
- 迷宫类逆向：把“格子函数”当图节点，`cmp imm + je + lea` 抽边，BFS 最短路；比动态跑省事。
- 判断生路/死路：跳转块里是 `lea rax,[rip+…]`（下一格）还是 `call trap`（禁制）。
- 用原程序回显作为最终验证（成功文案 + flag），别只信静态图。
