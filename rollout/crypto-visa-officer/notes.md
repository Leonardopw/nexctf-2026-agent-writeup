# 你 vs 签证官 · 笔记

## 关键点
- 目标：`219.216.64.241:35516`（Crypto，简单）。附件 `chall.py`：DSA 参数 p(2048-bit)、q(224-bit)、g=2^((p-1)/q) mod p，
  `y = g^x mod p`（x 随机），`m` 随机 32 字节，`h = sha256(m) >> (256-q.bit_length())`。
- `verify(y, m, r, s)`：
  1. `0 < r < q or s <= 0` → False；
  2. `s %= q`；`w = pow(s, q-2, q)`（模 q 求逆）；
  3. 判定 `pow(g, h*w % q, p) * pow(y, r*w % q, p) % p % q == r`。
- 漏洞：只检查了 `s <= 0`，没有检查 `s % q != 0`（标准 DSA 要求 `0 < s < q` 且 s 可逆）。
  取 `s = q` → `s % q = 0` → `w = pow(0, q-2, q) = 0` → 两个指数都是 0
  → `1 * 1 % p % q = 1`，于是只要 `r = 1` 就恒通过。

## 判定
- **输入 r=1, s=q**，服务端返回 flag；两次连接（y、m 都不同）flag 相同。

## 失败分支（排除理由）
- 不需要离散对数/私钥：正常伪造 DSA 签名要解 DLP，本题直接用退化输入绕过。
- 也试过“s 为 q 的倍数”这一族，等价于 s=q；r 必须取 1，因为左侧恒为 1。
